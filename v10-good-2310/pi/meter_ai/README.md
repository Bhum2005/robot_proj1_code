# meter_ai — AI แนะนำเลขมิเตอร์

ที่มา: โฟลเดอร์ `robot/meter_ai/` ของ robot-update (ชุดกล้อง PiVistation 5 เดียวกัน)
ใช้แค่ OpenCV + numpy (`sudo apt install --no-upgrade python3-opencv`) โมเดล `meter_digits.onnx`
อ่านมิเตอร์จำลองตัวสีน้ำเงิน + ตัวอักษร REAI สีส้ม + แถบเลข 4 หลัก

ที่ทีมเราแก้เพิ่ม (16 ต.ค. 2569) — เพราะกระดาษ/ตัวเลขอาจเปลี่ยนสี
- `strip.py`: หาแถบเลขได้แม้กระดาษไม่ใช่สีขาว (ทุกอย่างในตัวมิเตอร์ที่ไม่ใช่สีน้ำเงิน)
  กระดาษแดง/ส้ม/ชมพูแยกจาก REAI ด้วยรูปร่าง (ก้อนใหญ่สุด) และหาทิศ REAI แบบกันขอบกระดาษ
- `preprocess.py`: `paper_to_white()` วาดแถบสีใด ๆ ใหม่เป็นหมึกดำบนกระดาษขาว (ระยะสีใน Lab)
- `reader.py`: ลองทุกวิธีหา + ขยับกรอบเล็กน้อย (เฉพาะกระดาษสี) แล้วเลือกที่มั่นใจสุด
- กระดาษขาวเดิม: วิธีเดิมของ robot-update ยังอยู่ครบ (โหมด "white")
- ผลทดสอบ (`tests/metertest.py`): สี 12 แบบ x 4 ทิศ แนะนำถูก 46/48 แนะนำผิด 0,
  ภาพที่ไม่ควรได้เลข (กระดาษเปล่า/ไม่มีแถบ/เบลอ/ไม่มีมิเตอร์) แนะนำผิด 0
- ข้อจำกัด: กระดาษสีน้ำเงิน (กลืนกับตัวมิเตอร์) ใช้ไม่ได้ ; ทดสอบด้วยภาพจำลองจากรูปจริงใบเดียว
  ต้องเก็บรูปจริงจากหุ่นมาทดสอบเพิ่ม

## โมเดลเทรนใหม่ (16 ต.ค. 2569 สาย) — `meter_digits.onnx`
เทรนจากคลิปจริง 3 คลิป (มิเตอร์ 7527 2045 8785 5977 6201 2664) + ช่องตัวเลขสลับ + ตัวเลขวาดจากฟอนต์
ทดสอบกับคลิปที่ 4 ที่ไม่ได้ใช้เทรน (ผ่าน OpenCV 4.6 เหมือน Pi):

| | รุ่นเดิม robot-update | รุ่นใหม่ |
|---|---|---|
| แถบชัด 951 แถบ: อ่านถูก / แนะนำผิด | 95.8% / 2 | 95.7% / 0 |
| แถบเลขชุดใหม่ 900 แถบ: อ่านถูก | 79.1% | 94.1% |
| แถบเบลอจนอ่านไม่ออก 248 แถบ: แนะนำ (ควรเป็น 0) | 18 | 0 |
| ทั้งสายบนเฟรมคลิป 4: แนะนำถูก / ผิด | 164 / 1 | 176 / 0 |
| กระดาษสีจำลอง 48 ภาพ: แนะนำถูก / ผิด | 46 / 0 | 42 / 0 |

- เลข 3 ไม่มีในคลิปจริง วัดได้แค่กับแถบวาด (ถูก 290/300 แนะนำผิด 0) — ต้องเก็บคลิปที่มีเลข 3 มายืนยัน
- รุ่นเดิมเก็บไว้ที่ `meter_digits_robot_update.onnx` สลับกลับ: `ROBOT_METER_MODEL=/home/pi/server/meter_ai/meter_digits_robot_update.onnx`
- วิธีเทรนซ้ำ: `ai-training/README.md`

## น้ำหรือไฟ + ตัวเรือนสีอื่น (16 ต.ค. 2569 เย็น)
- `kind.py`: แยกจากรูปทรงตัวเรือน — ทรงกระบอก (ขอบโค้ง เข้ากับวงรี) = น้ำ / กล่องสี่เหลี่ยมติดผนัง = ไฟ
  เทรนน้ำหนักจากเฟรมคลิปจริง 298 เฟรม (น้ำ 7527 2045 8785 · ไฟ 5977 6201 2664)
  กันคลิปออกทีละคลิป: ถูก 294/298 ตัวที่ผิดมั่นใจแค่ ~0.52 -> ที่ >= 0.75 ไม่มีผิด
  บอกชนิดเฉพาะเมื่ออ่านเลขได้มั่นใจ >= 0.6 (กันก้อนสีอื่นที่ไม่ใช่มิเตอร์)
- `locate.py`: ไม่เจอตัวเรือนน้ำเงิน -> ลองแดง ส้ม เหลือง เขียว ฟ้า ม่วง (ของเดิมไม่เปลี่ยน)
- `reader.py`: ไม่รู้ทิศ (ไม่เห็น REAI หรือตัวเรือนสีส้มแดงกลืน REAI) -> ลองกลับหัวด้วย
- ชุดทดสอบ: `ai-training/gen_scenes.py` (เปลี่ยนสีตัวเรือน + แปะแถบเลขสีสุ่ม ฟอนต์ที่ไม่ได้ใช้เทรน)
  วัดด้วย `ai-training/evalscenes.py`
