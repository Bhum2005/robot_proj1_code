# meter_ai — AI แนะนำเลขมิเตอร์

ที่มา: โฟลเดอร์ `robot/meter_ai/` ของ robot-update (ชุดกล้อง PiVistation 5 เดียวกัน)
ใช้แค่ OpenCV + numpy (`sudo apt install --no-upgrade python3-opencv`) โมเดล `meter_digits.onnx`
อ่านมิเตอร์จำลองตัวสีน้ำเงิน + ตัวอักษร REAI สีส้ม + แถบเลข 4 หลัก

ที่ทีมเราแก้เพิ่ม (16 ต.ค. 2569) — เพราะกระดาษ/ตัวเลขอาจเปลี่ยนสี
- `strip.py`: หาแถบเลขได้แม้กระดาษไม่ใช่สีขาว (ทุกอย่างในตัวมิเตอร์ที่ไม่ใช่สีน้ำเงิน)
  กระดาษแดง/ส้ม/ชมพูแยกจาก REAI ด้วยรูปร่าง (ก้อนใหญ่สุด) และหาทิศ REAI แบบกันขอบกระดาษ
- `preprocess.py`: `paper_to_white()` วาดแถบสีใด ๆ ใหม่เป็นหมึกดำบนกระดาษขาว (ระยะสีใน Lab)
- `reader.py`: ลองทุกวิธีหา + ขยับกรอบเล็กน้อย (เฉพาะกระดาษสี) แล้วเลือกที่มั่นใจสุด
- กระดาษขาวเดิม: วิธีเดิมของ robot-update ยังอยู่ครบ (โหมด "white")
- ผลทดสอบ (`tests/metertest.py`): สี 12 แบบ x 4 ทิศ แนะนำถูก 46/48 แนะนำผิด 0,
  ภาพที่ไม่ควรได้เลข (กระดาษเปล่า/ไม่มีแถบ/เบลอ/ไม่มีมิเตอร์) แนะนำผิด 0
- ข้อจำกัด: กระดาษสีน้ำเงิน (กลืนกับตัวมิเตอร์) ใช้ไม่ได้ ; ทดสอบด้วยภาพจำลองจากรูปจริงใบเดียว
  ต้องเก็บรูปจริงจากหุ่นมาทดสอบเพิ่ม
