# เฟิร์มแวร์ ESP32-S3 (v9)

`main.cpp` — Arduino framework ใช้แค่ `Wire` (ไม่ต้องลงไลบรารีเพิ่ม) แฟลชด้วย Arduino IDE หรือ PlatformIO
คุยกับ Pi ทาง USB serial 115200

| ส่วน | ฮาร์ดแวร์ |
|---|---|
| ล้อ | มอเตอร์ JGB ผ่าน MDD3A |
| แปรง | TT motor สองตัวผ่าน MX1508 |
| แขนกล้อง | servo สองตัวบน PCA9685 (I2C 0x40, SDA 8 / SCL 9) ช่อง 7 = pan, ช่อง 4 = tilt |

คำสั่งหลักจาก Pi
- บรรทัด `#M` (ความเร็วล้อ) `#S` (มุมแขน) `#H` `#T` — server.py ส่งเองทุก 50 ms
- ตัวอักษรเดี่ยว: `X` หยุดฉุกเฉิน (ล้อ + แปรง) · `k` เปิด/ปิดแปรง · `r` วนทิศแปรง · `?` ถามรุ่น

ความปลอดภัยในตัว
- ขาดคำสั่งจาก Pi 400 ms → ล้อหยุด · Pi เงียบ 2 วิ → ดับแปรง
- servo soft start ทีละตัวตอนบูต กันกระแสกระชากจนไฟตก
