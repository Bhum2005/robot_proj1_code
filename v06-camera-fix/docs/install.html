สามเครื่อง: Ubuntu เก็บข้อมูลและเป็นเว็บ · Raspberry Pi คุมหุ่นและถ่ายรูป · ESP32 ขับมอเตอร์ ทำตามลำดับจากบนลงล่าง ใช้เวลาประมาณหนึ่งชั่วโมงครึ่ง

เตรียม Ubuntu Pi ESP32 ทดสอบ แก้ปัญหา

ก่อนเริ่ม

ตรวจของให้ครบก่อน จะได้ไม่ต้องหยุดกลางทาง

เครื่องไฟล์ที่ต้องมีหน้าที่
Ubuntu
เครื่องที่เปิดตลอด		 hub.py pages.py
meterhub.service		 เว็บลูกบ้าน เว็บเจ้าของหอ เก็บรูปทั้งหมด

ลำดับสำคัญ ทำ Ubuntu ให้เสร็จก่อนเสมอ เพราะตอนตั้งค่า Pi ต้องกรอก IP และโทเคนของ Ubuntu ลงไป ถ้าทำ Pi ก่อนจะต้องย้อนกลับมาแก้

สองเครื่องต้องอยู่วง WiFi เดียวกัน Ubuntu กับ Pi ส่งรูปกันในวง ส่วน ESP32 ไม่ต่อเน็ตเลย ต่อสาย USB เข้า Pi อย่างเดียว

จดค่าพวกนี้ไว้ จะใช้ซ้ำหลายที่

ช่องพวกนี้ช่วยกันลืมระหว่างทำ ปิดหน้าแล้วข้อมูลหาย จดใส่กระดาษด้วย

เครื่องที่ 1

Ubuntu

เครื่องนี้เก็บรูปและเลขมิเตอร์ทั้งหมด และเป็นเว็บที่ทั้งลูกบ้านและเจ้าของหอเข้า ต้องเปิดตลอดเวลา ถ้าเป็นโน้ตบุ๊กต้องเสียบไฟทิ้งไว้

  1. วางไฟล์และลงของที่ต้องใช้

    hub.py กับ pages.py ต้องอยู่โฟลเดอร์เดียวกัน ไม่งั้นจะขึ้น ModuleNotFoundError: pages

    mkdir -p ~/meterhub-app
cd ~/meterhub-app
# คัดลอก hub.py และ pages.py มาไว้ที่นี่
sudo apt update
sudo apt install -y python3-pil

  2. สุ่มโทเคนสำหรับให้หุ่นส่งรูป

    เป็นคนละตัวกับรหัสเข้าเว็บโดยตั้งใจ ถ้าหุ่นหายให้เปลี่ยนแค่โทเคน ไม่ต้องเปลี่ยนรหัสที่แจกลูกบ้านไปแล้ว

    openssl rand -hex 16

    จดค่าที่ได้ใส่ช่อง โทเคนส่งรูป ข้างบน จะต้องใช้อีกสองที่

  3. ตั้งรหัสเจ้าของหอ

    อย่างน้อย 12 ตัว และไม่ซ้ำกับรหัสที่ใช้ที่อื่น เพราะรหัสนี้เปิดหน้าคุมหุ่นได้ด้วย

    python3 hub.py --dir ~/meterhub --owner-pw รหัสที่ตั้งเอง

    ถ้าไม่ใส่ --owner-pw ตอนเปิดครั้งแรก ระบบจะสุ่มรหัสมาให้แล้วพิมพ์บนจอครั้งเดียว

  4. ลองรันดูก่อน

    HUB_TOKEN=โทเคนที่สุ่มมา python3 hub.py \
  --port 8080 \
  --dir ~/meterhub \
  --owner-path /<ทางลับเจ้าของหอ>

    มันจะพิมพ์ที่อยู่ออกมาสามบรรทัด เปิดอันที่เป็นเว็บเจ้าของหอในเบราว์เซอร์ ล็อกอินด้วยรหัสจากขั้นที่ 3 ลองเพิ่มห้องทดสอบสักห้อง แล้วกด Ctrl+C

    --owner-path คือทางเข้าของเจ้าของหอ ตั้งให้เดายากเพราะเว็บจะอยู่บนอินเทอร์เน็ตจริง หน้าลูกบ้านไม่มีอะไรบอกใบ้ทางเข้านี้เลย

  5. ติดตั้ง Tailscale แล้วจดที่อยู่ถาวร

    ทำข้อนี้แทนการจอง IP ที่เราเตอร์ เพราะถ้าใช้ WiFi ของมหาลัยหรือหอ เราเข้าหน้าเราเตอร์ไม่ได้ และ IP จะเปลี่ยนเรื่อย ๆ

    curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
sudo tailscale set --operator=$USER
tailscale status

    คำสั่งที่สองจะพ่นลิงก์มา เปิดแล้วล็อกอินด้วย Google กดอนุญาต จากนั้น tailscale status จะโชว์เลขขึ้นต้นด้วย 100. นั่นคือที่อยู่ถาวรของเครื่องนี้ จดใส่ช่อง ที่อยู่ Tailscale ของ Ubuntu ข้างบน

    ทำไมถึงดีกว่าจอง IP เลข 100.x.x.x ติดกับเครื่อง ไม่ได้ติดกับวง WiFi ย้ายไปเกาะเน็ตที่ไหนก็ยังส่งถึงกัน และถ้า WiFi ที่ใช้กันไม่ให้เครื่องในวงคุยกันเอง (เจอบ่อยในหอและมหาลัย) Tailscale จะอ้อมให้เอง ซึ่งการส่งรูปในวงธรรมดาทำไม่ได้

  6. ตั้งไม่ให้เครื่องหลับ

    ข้ามได้ถ้าเป็นเครื่องตั้งโต๊ะ แต่โน้ตบุ๊กต้องทำ ไม่งั้นปิดฝาแล้วเว็บดับทั้งหอ

    sudo systemctl mask sleep.target suspend.target hibernate.target

  7. ให้รันเองตลอด

    ข้ามข้อนี้ไปก่อนถ้ายังไม่ได้ลง Tailscale บน Pi บรรทัด --robot ต้องใส่ที่อยู่ Tailscale ของ Pi กลับมาทำข้อนี้หลังทำ Pi ขั้นที่ 2 เสร็จ

    sudo cp meterhub.service /etc/systemd/system/
sudo nano /etc/systemd/system/meterhub.service

    ในไฟล์ต้องแก้ห้าจุด

    บรรทัดแก้เป็น
    User=ชื่อผู้ใช้จริงบนเครื่อง
    WorkingDirectory=พาธเต็มของ ~/meterhub-app
    HUB_TOKEN=โทเคนจากขั้นที่ 2
    ExecStartเติม --owner-path และ --robot http://<ที่อยู่ Tailscale ของ Pi>:9000
    เพิ่มบรรทัด--robot-pass รหัสหน้าคุมหุ่นที่จะตั้งในขั้นที่ 7 ของ Pi
    sudo systemctl daemon-reload
sudo systemctl enable --now meterhub
systemctl status meterhub

  8. เปิด MagicDNS และใบรับรอง HTTPS

    สองอันนี้ Funnel บังคับต้องมี เปิดในหน้าเว็บ Tailscale แท็บ DNS

    เปิด MagicDNS และ HTTPS Certificates ชื่อ tailnet จะอยู่ในหน้านี้ด้วย หน้าตาประมาณ tail1a2b3.ts.net

  9. เปิด Funnel

    tailscale funnel 8080

    ครั้งแรกจะยังไม่ทำงาน แต่พ่นลิงก์มาให้กดอนุญาตก่อน กดแล้วสั่งซ้ำอีกที จะได้ลิงก์หน้าตาประมาณ https://ชื่อเครื่อง.tail1a2b3.ts.net

    ลองเปิดจากมือถือที่ปิด WiFi ถ้าขึ้นหน้าล็อกอินลูกบ้านแปลว่าใช้ได้ กด Ctrl+C แล้วสั่งให้รันค้าง

    sudo tailscale funnel --bg 8080
tailscale funnel status

  10. ทดสอบว่ารอดจากการรีบูต

    ข้อนี้คนข้ามบ่อยที่สุด แล้วมารู้ตอนไฟบ้านดับว่าระบบไม่กลับมาเอง

    sudo reboot

    พอเครื่องกลับมา เปิดลิงก์จากมือถือที่ปิด WiFi อีกครั้ง ต้องขึ้นหน้าล็อกอินเหมือนเดิม

เครื่องที่ 2

Raspberry Pi 5

เครื่องนี้อยู่บนหุ่น คุมมอเตอร์ผ่าน ESP32 ถ่ายรูปมิเตอร์ แล้วส่งขึ้น Ubuntu ทุก 20 วินาที

  1. เช็คว่าคุยกับ Ubuntu ได้

    ping -c 3 192.168.1.50

    ถ้า ping ไม่ผ่าน หยุดตรงนี้ก่อน ข้อต่อ ๆ ไปทำไปก็ไม่มีประโยชน์ ตรวจว่า Pi เกาะ WiFi วงเดียวกันอยู่จริง

  2. ลงของที่ต้องใช้

    sudo apt update
sudo apt install -y python3-serial python3-evdev python3-pil

    python3-evdev คือตัวที่ทำให้จอยใช้ได้ ถ้าไม่ลง หุ่นยังคุมผ่านเว็บได้แต่จอยจะไม่ทำงาน

  3. วางไฟล์

    mkdir -p ~/server
cd ~/server
# คัดลอก server.py (ตัวใหม่) และ push.py มาไว้ที่นี่
mkdir -p ~/robot_photos

    server.py ต้องเป็นตัวใหม่ ตัวที่มีกล่องถามเลขห้องตอนกดถ่าย และหยุดฉุกเฉิน ZL+ZR ถ้าใช้ตัวเก่าจะไม่มีสองอย่างนี้

  4. ลองส่งรูปรอบเดียว

    python3 push.py \
  --to http://192.168.1.50:8080 \
  --token โทเคนเดียวกับ Ubuntu \
  --once

    ถ้ายังไม่เคยถ่ายรูปเลยจะไม่มีอะไรส่ง ก็ถือว่าผ่าน ขอแค่ไม่ขึ้นข้อความแดง

    ถ้าขึ้นแบบนี้แปลว่า
    คลังปฏิเสธ (403)โทเคนสองฝั่งไม่ตรงกัน
    ยังต่อคลังไม่ได้IP ผิด หรือ hub ไม่ได้รันอยู่

  5. ตั้งรหัสหน้าคุมหุ่น

    รหัสนี้ต้องตรงกับ --robot-pass ที่ตั้งไว้ฝั่ง Ubuntu ไม่งั้นกดปุ่มคุมหุ่นแล้วจะเปิดไม่ขึ้น จดใส่ช่อง รหัสหน้าคุมหุ่น ข้างบน

  6. ให้ทั้งสองตัวรันเอง

    sudo cp robot-server.service /etc/systemd/system/
sudo cp robot-push.service /etc/systemd/system/
sudo nano /etc/systemd/system/robot-server.service   # แก้ ROBOT_PASS
sudo nano /etc/systemd/system/robot-push.service     # แก้ IP และโทเคน
sudo systemctl daemon-reload
sudo systemctl enable --now robot-server robot-push
    systemctl status robot-server
journalctl -u robot-push -f

  7. ทดสอบว่ารอดจากการรีบูต

    sudo reboot

    พอกลับมา เปิด http://raspberrypi.local:9000 ในวง ต้องขึ้นหน้าคุมหุ่นเอง โดยไม่ต้อง ssh เข้าไปสั่งอะไร

เครื่องที่ 3

ESP32-S3

ตัวนี้ไม่เกี่ยวกับระบบมิเตอร์เลย มันรับคำสั่งจาก Pi ทางสาย USB แล้วขับมอเตอร์ ไม่ต่อเน็ต ไม่มีอะไรต้องตั้งค่า แฟลชครั้งเดียวจบ

  1. เปิด main.cpp ใน Arduino IDE

    เลือกบอร์ดให้ตรงรุ่น ESP32-S3 ที่ใช้ แล้วเลือกพอร์ตที่เสียบอยู่

  2. แฟลชลงบอร์ด

    ต้องเป็น main.cpp ตัวใหม่ ตัวที่มีคำสั่ง X สำหรับหยุดฉุกเฉิน ถ้าใช้ตัวเก่า กด ZL+ZR แล้วล้อจะหยุดแต่แปรงยังหมุนอยู่ ซึ่งอันตรายกว่าล้อ เพราะมือเข้าไปติดได้

  3. เสียบสาย USB เข้า Pi

    เปิดหน้าคุมหุ่นดู ถ้าขึ้น ยังไม่เชื่อมกับ ESP32 — ตรวจสาย USB ให้เช็คสายกับไฟเลี้ยง ไม่ต้องไปยุ่งกับโค้ด

ทดสอบทั้งเส้น

ทำครบทุกข้อก่อนแจกรหัสให้ลูกบ้าน ถ้าข้อไหนไม่ผ่านให้หยุดแก้ตรงนั้นก่อน

  • เปิดลิงก์เว็บจากมือถือที่ปิด WiFi แล้วขึ้นหน้าล็อกอินลูกบ้าน
  • ล็อกอินเจ้าของหอที่ทางเข้าลับได้ และเพิ่มห้องจริงได้ 2 ห้อง พร้อมจดรหัสที่ระบบให้มา
  • กดปุ่ม "คุมหุ่น" ในเว็บเจ้าของหอแล้วเห็นภาพสดจากกล้อง
  • กดชัตเตอร์แล้วกล่องถามเลขห้องเด้งขึ้นมา กรอกห้องแรก เลือกน้ำ กดถ่าย
  • กดชัตเตอร์อีกครั้ง ค่าห้องเดิมยังค้างอยู่ เปลี่ยนเป็นไฟแล้วถ่าย
  • กลับมาหน้าเจ้าของหอ รอไม่เกิน 20 วินาที รูปเข้าห้องนั้นเอง
  • พิมพ์เลขที่อ่านได้ใต้รูป กดบันทึก จุดข้างเลขห้องเปลี่ยนเป็นทึบ
  • เปิดเว็บจากมือถืออีกเครื่อง ล็อกอินด้วยเลขห้อง+รหัสลูกบ้าน เห็นเลขและรูปของห้องตัวเอง
  • ลองล็อกอินห้องหนึ่ง แล้วเปิดรูปของอีกห้อง ต้องเข้าไม่ได้
  • กด ZL+ZR บนจอยพร้อมกัน ล้อหยุดและแปรงดับพร้อมกัน
  • ถอดปลั๊กเราเตอร์ 1 นาทีแล้วเสียบกลับ ระบบกลับมาเองทั้งสองเครื่อง

ผ่านครบ 11 ข้อแล้วค่อยเพิ่มห้องที่เหลือ รหัสของแต่ละห้องแสดงครั้งเดียว จดใส่กระดาษแล้วส่งให้เจ้าของห้องโดยตรง อย่าส่งในไลน์กลุ่มหอ

แก้ปัญหา

อาการสาเหตุที่พบบ่อย
ModuleNotFoundError: pages pages.py ไม่ได้อยู่โฟลเดอร์เดียวกับ hub.py
หน้าเว็บว่าง ไม่มีรูปสักใบ Pi ยังไม่ได้รัน push.py ดู journalctl -u robot-push -f
คลังปฏิเสธ (403) โทเคนสองฝั่งไม่ตรงกัน
รูปเข้ากล่อง "ยังไม่ได้ระบุห้อง" หมด ตอนถ่ายไม่ได้ใส่เลขห้อง หรือใส่เลขห้องที่ยังไม่ได้เพิ่มในระบบ
กดคุมหุ่นแล้วขึ้น "ต่อหุ่นไม่ได้" หุ่นปิดอยู่ หรือ --robot ชี้ผิดที่
คุมหุ่นได้แต่ภาพไม่ขึ้น --robot-pass ไม่ตรงกับ ROBOT_PASS บน Pi
ลูกบ้านเข้าไม่ได้ รหัสแสดงครั้งเดียวตอนสร้าง หายแล้วกด "ตั้งรหัสใหม่"
จอยไม่ทำงาน ยังไม่ได้ลง python3-evdev หรือจอยยังไม่ได้เปิดโหมด Xbox (A + Home)
ฟอนต์ไทยไม่สวย เครื่องโหลดฟอนต์จาก Google ไม่ได้ ระบบจะถอยไปใช้ฟอนต์ของเครื่องเอง

สำรองข้อมูล คัดลอกทั้งโฟลเดอร์ ~/meterhub ไปไว้ที่อื่น สัปดาห์ละครั้ง ข้างในมีรูปและเลขมิเตอร์ย้อนหลังทั้งหมด หายแล้วหายเลย ไม่มีฐานข้อมูล เป็นไฟล์ธรรมดา ย้ายเครื่องก็แค่คัดลอกโฟลเดอร์นี้ไปวาง

ระบบนี้ยังไม่คิดเงินและยังไม่ออกใบแจ้งหนี้ มีแค่เลขมิเตอร์กับหน่วยที่ใช้ และยังต้องคีย์เลขเอง การอ่านเลขอัตโนมัติด้วยชิป Hailo เป็นงานถัดไป
