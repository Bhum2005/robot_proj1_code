# เทรนโมเดลอ่านเลขมิเตอร์ใหม่ (ทำบนคอมที่มี PyTorch ไม่ใช่บน Pi)

ผลลัพธ์คือไฟล์ ONNX ขนาดเดียวกับเดิม (อินพุต 1x1x40x160 → 40 ค่า) ใส่แทน `pi/meter_ai/meter_digits.onnx` ได้ทันที
Pi ใช้แค่ OpenCV เปิดไฟล์ ไม่ต้องลงอะไรเพิ่ม (ทดสอบกับ OpenCV 4.6 แล้ว ผลตรงกัน)

ขั้นตอน (เครื่องที่ใช้: `pip install torch --index-url https://download.pytorch.org/whl/cpu onnx`)
1. ดึงเฟรมจากคลิป: `ffmpeg -i คลิป.mp4 -vf fps=4 -q:v 2 frames/c1/f_%04d.jpg` (คลิปละโฟลเดอร์ c1, c2, ...)
2. แก้ `KNOWN` ใน `harvest.py` เป็นเลขของมิเตอร์ทุกตัวที่อยู่ในคลิป แล้วรัน
   `python3 harvest.py ../../pi frames strips` → ตัดแถบเลขทุกมิเตอร์ทุกเฟรม + ติดป้ายเฉลยจากชุดเลขที่รู้
   (ตรวจป้ายด้วยตาเป็นตัวอย่างก่อนเสมอ)
3. `python3 evalsets.py strips evalsets.npz` (ใช้คลิปสุดท้ายเป็นชุดสอบ — ห้ามเอาไปเทรน)
4. `EVALSETS=evalsets.npz python3 train.py strips frames c1,c2,c3 c4 model.onnx 14` (~30 นาทีบน CPU 2 คอร์)
5. `python3 evalm2.py evalsets.npz ../../pi/meter_ai/meter_digits.onnx model.onnx` เทียบกับตัวที่ใช้อยู่
   ใช้ตัวใหม่เฉพาะเมื่อ A แนะนำผิด 0, C เบลอแนะนำ 0 และ B ไม่แย่กว่าเดิม

บทเรียนจากรอบ 16 ต.ค. (อย่าทำซ้ำ)
- ถ้าเอาแถบเลือน ๆ ที่ "ป้ายมาจากการเดา" ไปสอน โมเดลจะจำเลขทั้งชุดแล้วตอบมั่นใจกับภาพเบลอ (รอบแรกแนะนำผิดกับภาพเบลอ 100/248)
  → `train.py` ใช้เฉพาะแถบที่คมพอ + สอนภาพเบลอหนัก/ภาพขยะให้ "ไม่มั่นใจ" (ผลกระจายเท่ากันทุกเลข)
- คลิปมีมิเตอร์แค่ไม่กี่เลข → ต้องสลับช่องตัวเลขจริง + วาดตัวเลขจากฟอนต์ (มีเลข 3 ที่คลิปไม่มี) ให้โมเดลอ่าน "ตัวเลข" ไม่ใช่ "จำเลข"
